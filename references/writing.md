# 文档写作与定稿手册（展开）

本文件展开 SKILL.md §2.10 与 §7：方案、评审结论、事故说明、汇报、需求评论等一切给人读的文字在外发前怎么收紧。

# 文档写作与定稿手册（展开）

## 1. 文档类型与形态
- 多轮交付文档起草前先锁定文档章程：读者、用途、载体、篇幅预算、主导文体。
- 读者有多类时给每类各自的阅读路径，不写一份混合文档。
- 篇幅预算是硬上限，溢出拆到子页或附录，入口只加一行导航；不得靠提高上限消化增长。
- 先判使用者面模式（教程、操作、参考、解释），每份文档只保一个主导模式。
- 再判交付面文体族：方案架构、调研、现状梳理、评审发现、计划整改，判据是读者拿它做什么决定。
- 混族的病根是读者与决定不同却共用一套骨架；相邻族可同篇，但每段按各自骨架写。
- 方案族首稿必答：定位与命题定性、禁用词、非目标、备选与落选理由、本方案自身代价、外部先例、质量目标与验收场景、术语口径表、开放决策及其阻塞、退出与降级。
- 决策性章节按结论、约束、动作三段写；描述性章节不套三段。
- 计划族先写目标范围、依赖前置、风险应对，再列条目；没有完成判据的条目不进计划。
- 评审族的原始发现进工作底稿，结论面只放待裁决项与已裁决结果。
- 现状与目标分成两份文档，目标文档首句声明不代表当前生产能力。
- 正文结论先行：顶层一句主论点，其下分组支撑，证据在底层；组数服从内容不凑数。
- 证据与过程归独立工作底稿，收录标准是未参与的有经验同行能据此重建做了什么与如何得出结论。
- 敏感材料先判密级再写入，凭据绝不落入广泛分发的面；指向受控册只写记录号不写直链。
- 对已存在文档，形态不符只产出标记与建议，拆分合并由实质 owner 决定。

## 2. 已决点保全与修订节拍
- 中途新请求先对照章程分类：在章程内就地改，改章程就先重新确认再一次性重构，越界就挂起。
- 同一份文档出现第二次方向级纠正即章程未锁信号，停笔锁章程再重构一次。
- 全局修订（说什么：命题、结构、证据、分册）先于局部润色（怎么说），顺序不可倒。
- 判据看实质状态不看本轮措辞：命题未定即使只被要求改措辞也不进润色轮。
- 反之不成立：反复润色本身正常，不等于实质未定。
- 章程是起草闸不是实质 owner，实质决定仍来自用户或对应 owner。
- 跨模型协同评审的一致意见只是建议不是决定。
- 只接受命中元语、翻旧账、修辞尾、重复、低信息节的意见；一律拒绝口语化改书面和重新展开刻意精简的行。
- 呈现第二模型原话，然后说明采纳了什么、拒绝了什么、为什么。

## 3. 删什么留什么
- 唯一判据：只有仓库当前状态、没有会话记录和评审串的读者能否解析每个引用并核验每个断言。
- 不能解析的句子先把仍为真的事实改写成独立成立的现在时陈述，再删过程叙述；不含事实的整句删。
- 删死的会话引用：决策编号、审计编号、阶段代号、设计账本。
- 删堆栈视角：「后续 PR」「本次改动」「上一个 MR」，写已交付机制，未完成进 TODO 或 issue。
- 现状类页面删变更叙事：「以前 / 现在 / 不再」，回归写成现在时反事实而非仓库史。
- 删评审编排与对评审者辩护的注释，只留决定、理由与不变量。
- 删控制流复述与显然分支证明，只留非显然契约。
- hedge 与规划残留升级为带实际界限的 TODO，或直接写成界限。
- 强调只留给改变行为的那个从句，到处加粗等于没强调。
- 必须保留：issue 引用、抑制说明理由、实测数值及其出处词、稳定版本标识、外部标准章节号、运行时新旧状态、决策记录里的变更故事。
- 清扫前先枚举句中全部命题，防止把义务改成背书、把假设写成已交付。
- 顺序：先约定范围不推断全仓，冻结历史不动，批量探针只是线索必须逐条语义判断，先改源再改派生物。

## 4. 图表选型与记法
- 判别式是有无显式事件触发：有触发且关心生命周期画状态机，跨参与者消息顺序即主张画时序图，无触发自动流转画流程图，静态包含依赖画架构图。
- 没有时间顺序不画时序图，没有非法迁移不画状态机，静态包含关系不画成流程图。
- 架构视图三分：静态结构、运行时行为、部署拓扑，缺哪类即缺一类受众；每个关切至少被一个视图回答。
- 一张图一个抽象层，不混层。
- 硬约束：标题写图种与范围、有图例、每条线单向且标签具体、跨进程连线标协议、每元素标类型与职责、配色跨图一致并能过黑白打印。
- 时序图错误分支要么画要么图注声明只画正常路径；状态机状态穷尽且非法迁移显式、每条边标事件加守卫；流程图判定框出边覆盖全部取值。
- 图注写主张不写内容，「图 1：系统架构」是废话。
- 一句话说得更快就写那句话；画机制不画名字；互不相连的标注框是列表不是对比。
- 过期的图比没有图更糟，改了图描述的东西同一提交改图；评审看到过期图即使超范围也要标。
- 空间与时间关系优先出图；量级对比压进表格是载体错配，表适合逐条查证与精确取值。
- 图上的判断同样要能追到来源、表达不确定性、区分信息与假设，实体名在证据中命中为零即撤框。
- 布局取舍序：边交叉多于弯折多于对称，不为正交网格或出边夹角牺牲前者；交叉不可避免时角度越大越好。
- 语义不得只落在同一条色觉混淆线上的色对，需形状、图标或文字冗余。
- 首稿前冻结版式契约：画布比例、字号阶梯、色 token 及对比度、单格文本上限、分组单元；退役项写明理由；改契约即改规范。
- 不承载语义的笔画与文字用继承色，只有承载含义的色才写死。
- 正文对底对比度至少 4.5:1，大字至少 3:1；承载信息的加粗需语义标记，表格用真表头不用加粗行冒充。
- 目标端回读验收，不认本地检查器；卡片单元必须分组；交互源导出前全部展开再导并对照清点。
- 正文引用的图号必须存在；采用编号图注后每张图都要被正文引用；单张随文图不强制编号。

## 5. 术语与断言等级
- 规则依据分三档：有权威一手源可称基线、工程约定只防返工不得称最佳实践、查无来源的数字谁立谁先给出处。
- 已核无来源勿再立：加粗密度、每 N 字一图、一行不超过 40 汉字、留白提升理解 20%；每句不超 25 词只是单一机构风格可引用不可当标准。
- 同体裁实测分布只能描述位置，不能推出「写得好」或「优于同类」。
- 自评基准在初稿前建，抽样框与纳排规则先冻结再看自己的数，记录样本量口径局限，中英文分开统计。
- 找不到可比样本或决定不测时先如实记「未对标加原因」再下判断。
- 可发现性词汇的语料是同一检索面上同类的用词分布；高频未必该选，零频只证明发布方不用，要断言读者不这么搜需检索侧证据。
- 未公开的名字与定位词不拿去外部检索。
- 不确定性用固定七档词表并说明什么指标会改变它。
- 修订版要写本版判断相对上版的变化或一致性，没写是缺项。
- 每条载重结论显式证据状态：来源陈述、推论、作者判断。
- 调研结论进入方案文档时降为依据并附证据状态，不得升格为结论。
- 缩写只在明显缩短且本文反复使用时引入并首次解释；读者要操作的公共名称保留原名。
- 语域漂移查法：把本轮新写的句子单独拎出，逐个术语核对改动前文本是否出现过，未出现的候选二选一换成原文说法或当场白话解释。
- 收尾只读新句，读着不像原文同一人写的就是漂了。

## 6. 协作文档评论安全
- 编辑前先取真实标题并计数评论；有团队评论的文档永不整篇覆写，只做段落级定向替换或先导出全部评论。
- 评论按引用文本重锚定：引用子串逐字节保留即不孤儿，改了引用子串才孤儿。
- 重建有评论的节前列出每条评论的引用子串并逐字节保留。
- 自己的评论若锚定文本必须改，删除后在新文本重加；不主动 @ 人。
- 删除前重新拉取 id，不复用早先列表的 id。
- 改后重新列出全部评论核锚点与回复；计数上升可能是同事新评论，保留。
- 评论计数是权威孤儿检查，表格与标题的渲染文本可能与存储引用不一致，「找不到锚点」在此类内容上按误报处理除非计数下降。
- 写操作返回成功不等于已生效，回读目标块确认新文本存在才算完成。
- 验证走有限阶梯：直接回读、操作回执或版本号、有界最终一致重试、无权威读取则报「已接受未确认」而不报完成。
- 跨文档改名是评论安全工作不是查找替换：枚举引用文档、列出每条评论引用、逐节定向改、只动改名 token、每节后核计数不变。
- 引用芯片标题是首次提及时的快照，目标改名后需逐个重写引用并显式指定标签。
- 批注驱动修订：逐条判根因类（背景缺失、概念未定义、逻辑跳跃、措辞、事实引用错），按类全文扫同类位置一起修。
- 事实与引用错误走源核验不走措辞同类扫；授权只覆盖某节时全文扫描出候选但只在授权范围内编辑。

## 7. 交付面判定
- 逐面判定，未判定不得报已更新或已同步。
- 上传推送成功不等于远端已变，回读远端核到本轮可识别标志（新增段落、版本号、修订时间）才算已投放。
- 推不上去是 blocked 不是不投放，记已试补救、残余风险、下一步；有 blocked 面即不得报已同步。
- 放置前现读目标结构，不凭记忆、快照或链接标题猜父容器；落点选最具体的稳定容器，标题相似不构成父子依据。
- 新建移动后回读父容器、空间、完整路径；任务未载明落点的面标「选点自评、未经独立复核」并附完整路径。
- 放置前记下预期受众与预期 owner，来源必须是独立于本次投放的既有记录，投放者不得自拟基线也不得拿目标容器自身记录当预期。
- 放前先读目标容器生效边界与控制方：比预期宽、owner 非预期、无法核验的都不放；确知更窄的先修边界不做「先放再修」。
- 放后仍回读生效受众与 owner；已放入后发现更宽即已暴露，按待安全处置不得记回 blocked。
- 谁是权威以既有名册或治理记录为准，投放者不得自指权威，只认能从权威侧回读到的裁决记录。
- 私有暂存只适用于本就可持有的工作副本且边界回读确认仅本人可及，它是暂存不是交付，原面仍 blocked。
- 多代并存时给当前版稳定入口，旧版只用归档或原位标过期两种可逆方式退役；本清单不授权删除。
- 旧版含凭据、受删除请求的个人信息、有害操作说明时标待安全处置并转出，不自行判处置范围。
- 收尾按枚举走：先列全部面，逐面标四态之一（已投放、授权不投放、blocked、待安全处置），互斥不叠加。
- 授权不投放必须附可从授权方侧回读的记录，投放者自写理由不算。
- 拿不准是否命中安全处置按命中处理并问 owner。
- 含选点自评面的收尾报法不得出现「已同步」，报「已投放 N 面其中 M 面待复核」并附复核清单，由投放者以外有内容归置判断权的人确认后方可改报。

## 8. 执行卡与收尾记录范式
- 收尾整体回读默认在分享、提交、发布前触发；就地编辑线上文档顺延到最后一次写操作后。
- 逐刀都小不是跳过理由，重复、术语漂移、语域漂移只在整体回读才显形。
- 回读按缺陷类扫：重复（含本轮改出的同内容换面孔）、密块、术语漂移、语域漂移、单元格装不下列。
- 回读后记五项：回读的面、上次整体回读以来动过的块（扫描下限）、是否命中整卡扫描条件、查出的缺陷或写「无」、范围停在动过块的理由。
- 逐条守规则、只跑残留词 grep、实质内容评审三者单独或合计都不算回读证据。
- 批注修完以首次读者身份逐行通读被改段落。
- 每条动作可认领：有 owner、阶段、完成判据，缺一即不可认领。
- 开放决策单列并写明阻塞什么。
- 任何可由执行者自证的放行条件都视为漏洞，改为需外部记录或权威回读。

## 9. 去 AI 腔
- 删元语自证、修辞尾巴、编辑性括号、对已离场评审者的辩论。
- 删 hedge 如「大概够用」「先这样」，改写成实际界限。
- 强调通胀归零，只保留改变行为的从句。
- 不把用户认可的紧凑枚举与短行改回书面长句，短、白话、有力优先。
- 首句要兑现本段内容：先只读首句说出预期，再读全段核对，不符则据实改首句或拆段，不补造结论。
- 顺序有意义才用有序列表，否则用 bullet；同层项共同回答一个问题，条件原因放回所属步骤。
- 施动者只在读者要据此分工执行追责时点名，状态句不硬造主体。
- 只复制代码块仍需知道的占位值与条件放代码旁注释，长篇原理放正文；无注释格式用随附说明并保持载荷合法。
- 用宿主文档的词库写新句，不用自己的行话。

## 10. 检查器思路
- 先证明它能报失败再信它的绿：逐谓词 fixture 加干净控制组，控制组被误报即检查器有缺陷。
- 改判据必同步改 fixture，否则覆盖静默丢失。
- 对比度检查必须解析文本实际压着的底色，不假定白底；只有覆盖整幅画布的底板才按主题判。
- 底色解析不可信时整条跳过并显式报「未判定」，不能沉默成绿。
- 谓词钉在结构与实体上，不钉在文件名或标题词表上。
- 派生产物新鲜度两道判据：实体数与源一致加文件时间不早于源；新增派生产物当刻加进闸。
- 没有阈值依据就不设阈，只报数交人判断；无依据的测量走不影响退出码的信息档。
- 只有客观 ERROR 得阻断，代理型 WARN 不得设成阻断。
- 一条真缺陷判据不会在正常仓库命中 38% 文件，新增谓词前先在真实语料上量命中率。
- 已删除勿再加回的谓词：标题过长、单元格塞整段、段内并列枚举、列表项多句，它们拿宽度与计数当表达质量的代理。
- 排除项从检查器自身位置派生不得写死，且双向断言：fixture 被丢掉、长得像 fixture 的真文档被留下。
- 内联 SVG 不带脚本、外来对象、外部资源引用；样式与超链接不禁。
- 不可机械判定的仍归人：图种是否选对、图注是否是主张、图能否脱离正文独立看懂。
