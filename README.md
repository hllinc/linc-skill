# linc-skill

按 linc 的方式做研发的操作手册，供 Claude Code / Cursor 等 agent 加载。入口 `SKILL.md`（按风险分档的 playbook），展开手册在 `references/`。

安装：`git clone https://github.com/hllinc/linc-skill ~/.claude/skills/linc-skill`，然后在会话里 `/linc-skill`。

目录：`SKILL.md` 入口；`references/` 展开手册（交付、测试、评审发布、需求、文档、栈、可观测性、门禁）；`hooks/` 三个可选钩子与 settings 片段。
